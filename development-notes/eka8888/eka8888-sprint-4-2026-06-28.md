# Sprint 4: HTTP, RxJS & Testing — 2026-06-28

## What was done

This sprint I worked on the authentication and profile functionality of our ShopFront project.

Implemented features:

* Login with commercetools API
* Registration with commercetools API
* Profile page integration
* Profile update
* Address management (add, edit, delete)
* Default shipping and billing addresses
* HTTP Interceptor
* Form validation
* Unit tests

## Feature Component 1 – Registration

I built the registration form using Reactive Forms and HttpClient.

The biggest challenge was supporting both a single address and separate shipping and billing addresses. I solved it by adding a checkbox that allows users to use the same address or enter a different billing address.

I learned how commercetools handles customer addresses and improved my understanding of Reactive Forms.

## Feature Component 2 – Profile

I implemented the profile page where users can edit their personal information and manage addresses.

The most difficult part was updating customer data because commercetools requires the correct version when saving changes. I also worked with OnPush Change Detection and used `markForCheck()` when necessary.

## Testing

I wrote unit tests for my part of the project.

I tested authentication-related logic, token handling, validators, and HTTP requests. I also practiced mocking services with `jasmine.createSpyObj` and testing HTTP calls with `provideHttpClientTesting()` and `HttpTestingController`.
